# TamiBot Demo Landing

Versión demo de la landing pública de TamiBot, desplegada en GitHub Pages.

**No afecta producción** ([tamibot.com](https://tamibot.com)) — esto es un sitio paralelo en `tamibot.github.io/demo-landing/`.

Datos sembrados de **Líder Grupo Constructor** ([lider.com.pe](https://lider.com.pe)) — 9 proyectos en Lima y Arequipa.

## Desarrollo local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Push a `main` → GitHub Actions despliega automáticamente a Pages.

URL: https://tamibot.github.io/demo-landing/
